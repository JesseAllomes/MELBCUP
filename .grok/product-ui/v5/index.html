AsynymBet Sports, round 1

1 · Run sheet

Time is the layout. A vertical spine; each kick-off time is a giant numeral and the bets hang off it.

Spatial system one left rail timeline, content hangs right of the spine; sport page uses the same spine.

Type / roles Inter 800 at 46px for times (display), Inter 400-700 tabular for data; lock tokens, ring per lock.

Visual risk oversized tight-tracked clock numerals as the main headline, no card boxes.

Primary path read the top time, place that slot, scroll down for the next. First action = first slot.

Empty / error NFL has no multi: dashed note pointing to Home; nothing live: “next kick-off in Xh”.

2 · Slip stack

Each bet is a betting slip: legs on the body, a tear-off stub with chance, price and kick-off.

Spatial system single column stack of ticketed objects, 2-part grid per slip (body | stub). Sport page: games are slips too, stub = props entry.

Type / roles Inter 800 for stub price, 600 for selections; lock tokens; first slip lifted with the brand wash.

Visual risk perforation with real notch cut-outs (CSS mask) and dashed tear line as the identity.

Primary path top slip is the next to start, labelled Bet first; scroll for later ones.

Empty / error no NFL multi: dashed note; no multis at all: a blank slip “No bet clears the price right now”.

3 · Odds-range ladder

The five odds ranges are the rungs of a price ladder. Bar length is the price, so the trade-off between price and chance is visible.

Spatial system left axis rail, bars growing right from it, rungs ordered by price; sport page = same rail with over/under split bars.

Type / roles Inter 800 inside the bars for price, ring at the bar end per lock; kick-off as an amber time chip.

Visual risk price bars as the main graphic: long bar = big price = small ring.

Primary path scan rungs, pick the price you want, read its time chip; “bet first” tagged.

Empty / error a rung with no qualifying multi shows a faint empty rung: “Nothing clears the price in this range”.

4 · Game matrix

Games are rows, odds ranges are columns. You see which games feed which multi and where a game is shared.

Spatial system 5-column range header (ring, price, countdown), game rows with a 5-slot usage strip; sport page is a games x lines heat grid.

Type / roles Inter 800 tabular numbers in cells, 9.5-11px labels; cell brightness encodes fair %.

Visual risk the heat grid and usage strip are the interface; text list is secondary.

Primary path read the five header rings, pick a column, follow lit slots to its legs.

Empty / error sports with no leg get a dashed row; NFL no-multi dashed note; no data: header columns show “—”.
